# convert_flux
A python package for converting between astronomical fluxes, flux densities, and magnitudes

## Developer Installation

To install the convert_flux package from the source code use
```
git clone https://github.com/alexander-group/convert_flux.git
cd convert_flux
python -m pip install -e .[dev]
```

And then make sure to install the pre-commit hooks
```
pre-commit install
```
